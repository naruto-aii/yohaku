# 余白

白い雑音と、集中の時間。iPhone だけのためのアプリです。

画面の本体はタイマーです。音の切り替えも、設定も、購入も、同じ温かい灰色の上に置いています。タブも、バッジも、別の見た目の画面もありません。

アカウント、サーバ、解析、Android 版はありません。

## 画面

タイマーには、残り時間、開始と一時停止、連続の小さな数字、四つの音、設定があります。

集中が終わると、短い柔らかい音が鳴り、休憩がそのまま始まります。終わりを告げる画面は出しません。休憩が終わると同じ音が鳴り、次の集中は止まった状態で待っています。アプリを開いたまま離れても、終了時刻から続きを計算します。

音は白、ピンク、ブラウン、雨です。録音は使わず、その場で生成しています。選んだ音は集中のあいだ鳴り続け、休憩にも続きます。iOS のバックグラウンド再生により、アプリを離れても鳴ります。同じ音をもう一度押すと止まります。ロック画面の再生と一時停止も、この音だけを操作します。

設定では、集中と休憩の長さを変えます。無料のあいだは 25 分と 5 分のままです。

## 無料でできること

- 白い雑音
- 集中 25 分、休憩 5 分
- 連続の数字は、その起動中だけ見えます。保存はしません

## アンロックで増えること

生涯に一度の購入です。サブスクリプションでも、回数券でもありません。意図した価格は ¥4,980 です。金額はアプリのコードには書いていません。App Store Connect で製品 `yohaku_lifetime` に後から入れます。画面の価格は、StoreKit が返したものをそのまま出します。

- ピンク、ブラウン、雨
- 集中は 1〜120 分、休憩は 1〜60 分
- 連続を、この iPhone に保存します

連続は、途切れていない日々で終えた集中の回数です。同じ日に何度終えても、そのぶん増えます。丸一日あけると、次に終えたときから 1 です。昨日終えていれば、今日まだ始めていなくても、その数字は残っています。

購入できないときは、購入シートにその旨と製品 ID を出します。音のロックも、長さの変更も、そのシートを開きます。

## 育ちと棚

タイマーの下に、棚と引くがあります。最初から鉢の「丸」と植物の「薄い菊」を持っていて、その組み合わせで育ちが始まります。白い雑音も、25 分の集中も、この最初の植物も、あとの購入では隠しません。

時間は、集中が実際に進んだ分だけです。休憩は数えません。同じ日にもう一度集中すれば、その分も足します。育っているあいだはその花へ、育っていないあいだは次の花へ持ち越します。必要時間に達すると花が咲き、使っていた鉢と一緒に棚へ置きます。咲いた組は残ります。次の花は、持っている鉢と植物から始められます。時間がまだゼロのときだけ、鉢と植物を替えられます。

必要時間は、植物の時間を鉢の倍率で割ったものです。

| 稀少度 | 植物が咲くまで | 鉢の倍率 | 持っているものを引き当てたとき |
| --- | --- | --- | --- |
| N | 30 時間 | 1.1 | 1 時間 |
| R | 50 時間 | 1.2 | 3 時間 |
| SR | 100 時間 | 1.3 | 8 時間 |
| SSR | 200 時間 | 1.5 | 20 時間 |

薄い菊と丸なら 30 / 1.1 で、約 27.3 時間です。松と石なら 100 / 1.3 で、約 76.9 時間です。藤と薄磁なら 200 / 1.5 で、約 133.3 時間です。画面では「14.2 / 27.3 時間」のように出します。進み具合で、土、芽、葉、蕾、花と姿が変わります。

鉢も植物も 80 ずつです。内訳は N が 40、R が 24、SR が 12、SSR が 4。名前は短く、姿は形の数値からその場で描きます。画像ファイルは使いません。

稀少度は、その植物がどれだけ特別かで決めています。雑草、蒲公英、蓬は N です。雛菊、羊歯、菫は R です。松、白椿、南天は SR です。白菊、百合、藤、ラフレシアは SSR です。鉢は、素の土の形が N、釉や高台が R、石や面取りが SR、薄い磁器が SSR です。

## 引く

鉢か植物かを選んでから、一つ引きます。確率は N が 75%、R が 20%、SR が 4.5%、SSR が 0.5% です。同じ稀少度のなかでは、どれも同じ割合です。この割合は引く画面に出します。集中が 60 分たまると、引くものが一つ増えます。一回につき、一つ使います。

すでに持っているものを引いたとき、育っている花があれば上の表の時間を足します。その時間で咲けば、棚へ移したことも結果に書きます。育っている花がなければ、引くものを 0.5 足します。二つで一回引けます。

`yohaku_seed` は消耗型です。引くものを三つと、12 時間を足します。育っている花があればその時間へ、なければ次の花へ回します。同じ取引は一度だけです。価格は StoreKit が返す表示をそのまま出します。アプリの画面にも、この説明にも、円の請求額は書いていません。`Products.storekit` にある数値は、Mac 上のローカル確認用です。

生涯の `yohaku_lifetime` は、これまでのままです。

## 設計プレビュー

`preview/index.html` をブラウザで開いてください。ビルドは要りません。Finder でダブルクリックするか、ブラウザにファイルをドロップします。

タイマー、音の並び、購入シート、育ちの途中、棚、引く画面を、アプリと同じ見た目で並べた確認用のページです。購入シートの ¥4,980 は配置の確認であり、購入はできません。引く画面には円の金額を出していません。

## ビルド

Xcode 15 以降で `Yohaku.xcodeproj` を開きます。ターゲットは iOS 17 以上の iPhone だけです。実行するには、署名のチームを設定してください。

スキームは `Yohaku/Products.storekit` を参照しています。Mac 上では、この設定でローカルの StoreKit テストができます。ファイル内の表示価格はローカル確認用です。実際の価格は App Store Connect で設定します。消耗型の製品 ID は `yohaku_seed` です。

このリポジトリを用意した環境は Linux で、Xcode も Swift コンパイラもありません。そのため、この iOS アプリはコンパイルしていません。プロジェクトは SwiftUI の iOS アプリとして構成しています。

サンドボックス購入は、この環境では完了できません。製品 ID `yohaku_lifetime` と `yohaku_seed`、製品を読めないときの文言はアプリに入っています。
