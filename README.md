# 余白

白い雑音と、集中の時間。iPhone だけのためのアプリです。

画面は温かい灰色の上に置いています。タブも、バッジも、別の見た目の画面もありません。

アカウント、サーバ、解析、Android 版はありません。

## 画面

最初に、しずく 200 から植物を一つ、鉢を一つ受け取ります。どちらも毎回同じ N です。植物は蒲公英、鉢は丸です。

そのあと、始める前に音と、育てる植物と、使う鉢を選びます。白は無料です。ピンク、ブラウン、雨は生涯アンロックのあとです。

タイマーの画面は、育っている鉢が上、大きな残り時間が中央、しずくの数が下です。音の切り替えと、引くボタンは、この画面には置きません。戻ると、始める前の画面に戻ります。

集中が終わると、短い柔らかい音が鳴り、休憩がそのまま始まります。終わりを告げる画面は出しません。休憩が終わると同じ音が鳴り、次の集中は止まった状態で待っています。アプリを開いたまま離れても、終了時刻から続きを計算します。

音は白、ピンク、ブラウン、雨です。録音は使わず、その場で生成しています。選んだ音は集中のあいだ鳴り続け、休憩にも続きます。

設定では、集中と休憩の長さを変えます。無料のあいだは 25 分と 5 分のままです。

## 無料でできること

- 白い雑音
- 集中 25 分、休憩 5 分
- 連続の数字は、その起動中だけ見えます。保存はしません
- 蒲公英と丸から始まる育ちと、しずくで引くこと

## アンロックで増えること

生涯に一度の購入です。サブスクリプションでも、回数券でもありません。意図した価格は ¥4,980 です。金額はアプリのコードには書いていません。App Store Connect で製品 `yohaku_lifetime` に後から入れます。画面の価格は、StoreKit が返したものをそのまま出します。

- ピンク、ブラウン、雨
- 集中は 1〜120 分、休憩は 1〜60 分
- 連続を、この iPhone に保存します

連続は、途切れていない日々で終えた集中の回数です。同じ日に何度終えても、そのぶん増えます。

## しずく

通貨はしずくです。集中 60 分で 100、時間に比例します。休憩は数えません。1 回引くのに 100、10 回で 1000 です。10 回は、それぞれ別の抽選です。

有料のしずくは、高いパックほど一つあたりが安くなります。意図した価格は、40 で 160 円、150 で 480 円、380 で 1000 円、1200 で 2900 円、2200 で 4900 円、5000 で 10000 円です。製品 ID は `yohaku_shizuku_40`、`yohaku_shizuku_150`、`yohaku_shizuku_380`、`yohaku_shizuku_1200`、`yohaku_shizuku_2200`、`yohaku_shizuku_5000` です。画面に出す金額は StoreKit の `displayPrice` だけです。プレビューには円の請求額を書いていません。

`yohaku_seed` はありません。重複で 1、3、8、20 時間や、引くものを半分足す動きもありません。

## 育ちと棚

引いたものは、カタログの名前のまま植物の一覧か鉢の一覧に入ります。同じものを引くと、その個数が増えます。同じ植物は 80 の鉢と、同じ鉢は 80 の植物と組にできます。81 個目は数を増やさず、そのレア度の時間を 80 で割った分だけ育ちの時間に足します。

必要時間は、植物の時間を鉢の倍率で割ったものです。

| レア度 | 植物 | 鉢の倍率 |
| --- | --- | --- |
| N | 30 時間 | 1.1 |
| R | 50 時間 | 1.2 |
| SR | 100 時間 | 1.3 |
| SSR | 200 時間 | 1.5 |

蒲公英と丸なら 30 / 1.1 です。時間は集中した時間で、同じ日の追加の集中も足します。土、芽、葉、蕾、花のあいだを 32 段階に分けています。集中の区切りが終わるたびに、短くても絵は少なくとも一段階進んで見えます。必要時間に達するまでは咲きません。

咲いた組み合わせには、任意の名前を付けられます。棚では `植物名ー鉢名` と、付けた名前を出します。長音のダッシュです。

## 引く

鉢か植物かを選んでから引きます。枠の中は N 75%、R 20%、SR 4.5%、SSR 0.5% で、そのあと枠の中は均等です。一つあたりは N 1.875%、R 0.833%、SR 0.375%、SSR 0.125% です。

出るもの画面は、その枠の 80 を、名前とそれぞれの確率で並べます。名前を押すと絵が開きます。植物の絵は植物だけ、鉢の絵は空の鉢だけです。左端の植物は蒲公英です。

名前、レア度、絵は `catalog/CATALOG.md` が正本です。ここに無い種は出さず、引いたときに新しい名前も作りません。`art/` の絵は、名前と絵が食い違っていた項目の差し替えで、仮の平面イラストです。図鑑は `docs/zukan.html` です。

## ビルド

Xcode 15 以降で `Yohaku.xcodeproj` を開きます。ターゲットは iOS 17 以上の iPhone だけです。実行するには、署名のチームを設定してください。

スキームは `Yohaku/Products.storekit` を参照しています。ファイル内の表示価格は、Mac 上のローカル確認用です。実際の価格は App Store Connect で設定します。

このリポジトリを用意した環境は Linux で、Xcode も Swift コンパイラもありません。そのため、この iOS アプリはコンパイルしていません。

サンドボックス購入は、この環境では完了できません。生涯の製品 ID は `yohaku_lifetime` です。しずくの製品 ID は上のとおりです。
