# 余白

白い雑音と、集中の時間。iPhone だけのためのアプリです。

画面の本体はタイマーです。音の切り替えも、設定も、購入も、同じ温かい灰色の上に置いています。タブも、バッジも、別の見た目の画面もありません。

アカウント、サーバ、解析、Android 版はありません。

## 画面

タイマーには、残り時間、開始と一時停止、連続の小さな数字、四つの音、設定があります。

集中が終わると、短い柔らかい音が鳴り、休憩がそのまま始まります。終わりを告げる画面は出しません。休憩が終わると同じ音が鳴り、次の集中は止まった状態で待っています。アプリを開いたまま離れても、終了時刻から続きを計算します。

音は白、ピンク、ブラウン、雨です。録音は使わず、その場で生成しています。選んだ音は集中のあいだ鳴り続け、休憩にも続きます。iOS のバックグラウンド再生により、アプリを離れても鳴ります。同じ音をもう一度押すと止まります。ロック画面の再生と一時停止も、この音だけを操作します。

設定では、集中と休憩の長さを変えます。無料のあいだは 25 分と 5 分のままです。

## 無料でできること

- 白い雑音
- 集中 25 分、休憩 5 分
- 連続の数字は、その起動中だけ見えます。保存はしません

## アンロックで増えること

生涯に一度の購入です。サブスクリプションでも、回数券でもありません。意図した価格は ¥4,980 です。金額はアプリのコードには書いていません。App Store Connect で製品 `yohaku_lifetime` に後から入れます。画面の価格は、StoreKit が返したものをそのまま出します。

- ピンク、ブラウン、雨
- 集中は 1〜120 分、休憩は 1〜60 分
- 連続を、この iPhone に保存します

連続は、途切れていない日々で終えた集中の回数です。同じ日に何度終えても、そのぶん増えます。丸一日あけると、次に終えたときから 1 です。昨日終えていれば、今日まだ始めていなくても、その数字は残っています。

購入できないときは、購入シートにその旨と製品 ID を出します。音のロックも、長さの変更も、そのシートを開きます。

## 設計プレビュー

`preview/index.html` をブラウザで開いてください。ビルドは要りません。Finder でダブルクリックするか、ブラウザにファイルをドロップします。

タイマー、音の並び、購入シートを、アプリと同じ見た目で並べた確認用のページです。ここでの ¥4,980 は配置の確認であり、購入はできません。

## ビルド

Xcode 15 以降で `Yohaku.xcodeproj` を開きます。ターゲットは iOS 17 以上の iPhone だけです。実行するには、署名のチームを設定してください。

スキームは `Yohaku/Products.storekit` を参照しています。Mac 上では、この設定でローカルの StoreKit テストができます。ファイル内の表示価格はローカル確認用です。実際の価格は App Store Connect で設定します。

このリポジトリを用意した環境は Linux で、Xcode も Swift コンパイラもありません。そのため、この iOS アプリはコンパイルしていません。プロジェクトは SwiftUI の iOS アプリとして構成しています。

サンドボックス購入は、この環境では完了できません。製品 ID `yohaku_lifetime` と、製品を読めないときの文言はアプリに入っています。
