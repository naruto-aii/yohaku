# 余白 ガチャ図鑑

このファイルが名前、レア度、確率、成長、絵の正本です。ここに無い種は出しません。引いたときに新しい名前は作りません。

`art/` の絵は、名前と絵が食い違っていた項目の差し替えです。柔らかい平面の仮イラストで、元のボードの筆致とは揃っていません。各行に「差し替えの仮の平面イラスト」と書いてあります。植物のガチャ絵は植物だけ、鉢のガチャ絵は空の鉢だけです。左端の植物は蒲公英（`art/plant-n-tampopo.png`）です。

`crops/` にある写真は、確認用に残した元の切り抜きです。植物の写真には鉢とラベルが写っているものがあります。それらは図鑑の確認用で、植物ガチャの絵には使いません。ボード全体の実ファイルがこのリポジトリに無い行は、元のファイル名と位置を絵の欄に残しています。

成長は集中した時間です。植物は N 30時間、R 50時間、SR 100時間、SSR 200時間。鉢の倍率は N 1.1、R 1.2、SR 1.3、SSR 1.5。必要時間は植物の時間を鉢の倍率で割ったものです。

所持は品ごとに 80 までです。同じ植物は 80 の鉢と、同じ鉢は 80 の植物と組にできます。81 個目以降は数を増やさず、育ちの時間に足します。足す時間は、その品のレア度の時間（N 30、R 50、SR 100、SSR 200）を 80 で割ったものです。

確率は枠の中で N 75%、R 20%、SR 4.5%、SSR 0.5%。そのあと枠の中は均等です。一つあたりは N 1.875%、R 0.833%、SR 0.375%、SSR 0.125% です。10 連は、この抽選を 10 回別々に行います。
